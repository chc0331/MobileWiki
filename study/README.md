## 학습 목표와 진행 방식

**최종 목표:** 한국어 문서를 읽고 분류·요약하는 AI 기능을 Android 앱에 구현한다. 첫 결과물은 TXT·단순한 텍스트 PDF를 선택하면, 인터넷 없이 IT·경제·스포츠로 분류하고 핵심 문장을 최대 3개 보여 주는 앱이다.

**학습 환경:** PC·Mac의 Python에서 학습하고 Kotlin 앱에서 CPU로 실행한다. GPU가 필요하면 Colab을 쓴다. 온디바이스는 휴대폰에서 모델을 실행한다는 뜻이다. 스캔 PDF·OCR은 첫 범위에서 제외한다.

**진행 원칙:** 기간 대신 Chapter의 완료 기준으로 진도를 정한다. 쉬운 개념 → 작은 예제 → 직접 실습 → 이해 확인으로 배운다. Python이 낯설면 변수·리스트·함수·파일 읽기부터 익힌다.

## Chapter 1. AI와 머신러닝 기본 개념

**배울 내용 · 입문:** AI·머신러닝·딥러닝의 관계, 데이터·라벨·모델, 학습과 추론, 분류와 요약의 차이.

**실습·완료:** 짧은 문서를 직접 분류하고, 만들 앱의 입력·출력·실패 예시를 적는다. 학습과 추론을 자신의 말로 구분하면 완료. [개념·예제·실습 교재](chapter1/AI와_머신러닝_기본_개념.md)

## Chapter 2. 문서 데이터 처리와 전통적 머신러닝

**배울 내용 · 입문 → 초급:** TXT·PDF 텍스트 추출, 전처리, 학습·검증·테스트 분리, TF-IDF와 로지스틱 회귀, 원문에서 문장을 고르는 추출 요약.

**실습·완료:** 작은 문서 모음으로 분류기를 학습하고 핵심 문장을 고른다. 새 문서로 평가하고 오답을 설명하면 POC A 완료.

## Chapter 3. Android 온디바이스 추론 입문

**배울 내용 · 초급:** 모델 로딩, PC·앱의 입력 처리 일치, 백그라운드 실행·취소, 파일 선택부터 결과 표시까지의 흐름.

**실습·완료:** Chapter 2의 어휘·가중치를 앱에서 읽어 같은 계산을 구현한다. 비행기 모드에서 동작하고 같은 문서의 PC·앱 결과가 일치하면 POC B 완료.

## Chapter 4. 딥러닝 기초와 PyTorch

**배울 내용 · 초급:** Tensor와 Shape, 작은 신경망, 오차를 나타내는 Loss, 가중치 조정, 과적합. 필요한 수학만 예제로 익힌다.

**실습·완료:** 작은 모델을 학습·저장·재실행한다. 학습 데이터와 새 데이터의 결과 차이를 설명하고 추가학습 코드의 흐름을 읽으면 완료.

## Chapter 5. 자연어 처리와 사전학습 모델 이해

**배울 내용 · 초급:** 글을 토큰으로 나누는 tokenizer, 단어를 숫자로 표현하는 embedding, attention·Transformer의 역할, 입력 길이 제한.

**실습·완료:** 작은 한국어 사전학습 모델에 문서를 넣고 토큰 수·입력 길이를 바꿔 본다. 전처리·모델·출력의 연결과 긴 문서의 처리 방법을 설명하면 완료.

## Chapter 6. 기존 분류 모델 추가학습

**배울 내용 · 중급:** 사전학습 모델을 내 문서에 맞추는 fine-tuning, 학습 설정, 데이터 누출 방지, 종류별 성능과 오답 비교.

**실습·완료:** Android 변환·실행 가능성을 먼저 확인한 작은 모델을 추가학습한다. Chapter 2의 기준 모델과 같은 테스트 자료로 비교하고 개선 여부를 판단하면 완료.

## Chapter 7. 모델 배포와 경량화

**배울 내용 · 중급:** 모델 변환과 Android 실행, 숫자의 정밀도를 낮춰 크기를 줄이는 양자화, 품질·속도·메모리의 관계.

**실습·완료:** ONNX Runtime CPU 추론과 INT8 양자화를 실험한다. 같은 실기기에서 원본·경량 모델의 품질과 실행 비용을 비교해 앱에 적용하면 POC C 완료.

## Chapter 8. 생성형 요약과 효율적인 추가학습 입문

**배울 내용 · 중급:** 새 문장을 쓰는 생성형 요약, 프롬프트, 긴 문서 분할, 원문에 없는 내용 생성 문제. LoRA·QLoRA 추가학습은 선택 확장으로 다룬다.

**실습·완료:** 기존 소형 모델로 생성형 요약을 시험하고 추출 요약과 비교한다. 원문 충실도·누락·처리 시간을 확인하고, 기기 실행 가능성까지 판단하면 POC D 완료.

## 단계별 POC와 확인할 결과

POC는 기능이 가능한지 작은 범위로 확인하는 시제품이다. 각 단계에서는 같은 문서로 이전 결과와 비교한다.

| 단계 | 만들 결과 | 완료 확인 |
| --- | --- | --- |
| POC A · Chapter 2 | PC 문서 분류·추출 요약 도구 | 저장 후 재실행, 새 문서 평가, 오답 기록 |
| POC B · Chapter 3 | 첫 오프라인 Android 앱 | 비행기 모드, PC·앱 결과 일치, UI·취소 동작 |
| POC C · Chapter 7 | 추가학습·경량화 모델 적용 앱 | 품질, 모델 크기, 로딩·분석 시간, 메모리 |
| POC D · Chapter 8 | 생성형 요약 비교 시제품 | 원문 충실도·누락·실행 비용으로 채택 판단 |

**평가 원칙:** 학습 자료와 테스트 자료를 분리하고, 분류 오답과 요약문을 직접 읽는다. 앱 연결은 에뮬레이터에서 확인하되, 성능은 중급형·구형 실기기에서 측정한다. 결과와 남은 문제를 기록한 뒤 다음 Chapter로 넘어간다.

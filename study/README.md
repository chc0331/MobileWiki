## 최종 목표와 진행 방식

**목표 1 · 문서 요약 모델 설계:** 한국어·영어 문서를 원문 언어로 요약한다.

**목표 2 · 비지도 학습 모델 설계:** 문서 내용을 보고 N개 카테고리로 분류한다.

**비지도 분류:** 여러 문서를 정답 라벨 없이 유사한 내용끼리 묶는 군집화다. N은 설정하는 그룹 수이며, 카테고리명은 대표 문서·핵심어를 사람이 검토해 정한다.

**설계·실행:** 기존 모델·알고리즘을 조합하고 필요시 추가학습한다. PC·Mac·Colab에서 학습하고 Kotlin 앱의 CPU로 검증한다. 입력은 한·영 TXT·텍스트 PDF이며 OCR은 후속 범위다.

**진행 원칙:** Python 기초 → 개념 → 예제 → 실습 → 이해 확인 순서로, 기간 대신 완료 기준에 따라 진행한다.

## 단계별 POC와 확인할 결과

POC는 기능이 가능한지 작은 범위로 확인하는 시제품이다. 각 단계에서는 같은 문서로 이전 결과와 비교한다.

| 단계 | 만들 결과 | 완료 확인 |
| --- | --- | --- |
| POC A · Chapter 2 | PC 군집·추출 요약 도구 | N개 그룹, 대표 문서·핵심 문장 검토 |
| POC B · Chapter 3 | 첫 오프라인 Android 앱 | 저장된 군집에 새 문서 배정, PC 결과 재현 |
| POC C · Chapter 7 | 임베딩·군집 모델 적용 앱 | 군집 설계안, 품질·크기·속도·메모리 비교 |
| POC D · Chapter 8 | 문서 요약 모델 설계·시제품 | 원문 충실도·누락·실행 비용으로 설계 선택 |

**평가 원칙:** 한국어·영어를 각각 평가한다. 군집은 대표 문서·반복 실행 안정성과 [실루엣 점수](https://scikit-learn.org/stable/modules/clustering.html#silhouette-coefficient)를 함께 보고, 요약은 사실성·핵심 내용 보존을 확인한다. 점수만으로 주제 적합성을 보장하지 않으며, 속도·메모리는 실기기로 측정한다. 요약 추가학습·최종 평가 문서는 분리한다.

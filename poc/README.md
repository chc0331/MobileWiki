# SLM Wiki POC 한 페이지 요약

문서 버전: 0.2 · 작성일: 2026-10-27 · 현재 상태: 임베딩 하위 POC 잠정 평가 완료·사람 검수 대기, 앱 실현 가능성 미판정

SLM Wiki는 인터넷 없이 한국어 메모를 정리하는 Android 앱이다. 육아와 직장을 병행하는 사람이 병원·어린이집·여행·연차 기록을 다시 찾도록 돕는다. “지난번 소아과에서 받은 해열제 이름이 뭐였지?”라고 물으면 기록에 있는 이름과 근거 메모를 보여 준다. 기록에 없는 복용법이나 진단은 만들지 않는다.

## 무엇을 검증하나

작은 언어 모델(SLM, Small Language Model)이 스마트폰의 제한된 저장 공간과 메모리 안에서 쓸 만한 품질을 내는지 확인한다. 출시 준비보다 품질·자원·실사용의 가능성 판정이 목적이다. 먼저 PC에서 EmbeddingGemma 2의 한국어 텍스트 검색·문서 묶기 미세 조정을 시험한다. 가상 메모는 로컬 Qwen3 모델로 만들고, 생성 모델의 학습과 Android 통합은 다음 단계에서 다룬다. 데이터와 모델 산출물은 Hugging Face Hub의 비공개 저장소에서 버전별로 관리한다.

| 항목 | 이번 POC의 기준 |
| --- | --- |
| 환경 | Android 12 이상, ARM64, RAM 8GB 중급기, CPU 전용 |
| 규모·입력 | 메모·문서 1,000건. 직접 작성, TXT·Markdown·텍스트 PDF. 5,000건은 확장 시험 |
| 기능 | 메모 작성·가져오기, 자동 묶음, 요약·개념·날짜 추출, 낱말+의미 검색, 짧은 단일 질문 답변, 개념 그래프·페이지, 수정·삭제, 수동 내보내기·복원, 견본·피드백 |
| 화면·처리 | 메모·묶음·그래프·검색 4개 탭. 저장 후 빠른 색인, 백그라운드 정리, 24시간 주기 재군집 요청, 필요할 때 개념 페이지·답변 생성 |
| P1 오프라인 | 모델을 포함한 설치본으로 첫 실행부터 동작. 앱에 인터넷 권한 없음 |
| P2 개인정보 | 자동 외부 전송·백업·기기 이전 금지. 사용자가 직접 실행하는 내보내기만 예외 |
| P3 신뢰성 | 요약·답변 각각 사실 오류가 있는 출력 비율 5% 이하. 근거 표시와 답변 보류를 함께 평가 |
| 자원 | 임베딩·생성 모델 필수 파일 합계 1GB 이하. 모델 미로딩 상태 대비 최대 추가 메모리 1.5GB 이하 |
| 산출물 관리 | 평가용 합성 데이터와 모델·변환물은 Hugging Face Hub 비공개 저장소에서 버전 관리. 사용자 메모는 업로드하지 않음 |
| 먼저 할 임베딩 실험 | M2 Mac에서 텍스트 전용 EmbeddingGemma 2를 학습 전후 비교. 검색·묶음 품질을 확인하고 문서에 나온 표현으로 묶음 이름을 붙임 |
| 품질·속도 | 검색 상위 5개 근거 포함률 90% 이상, 답변 가능 질문 정답률 85% 이상. 검색 p95 2초·짧은 답변 p95 20초 이하 |
| 실사용 | 본인 1인·7일, S1~S10 중 8개 이상 성공, 데이터 손실 0건 |

p95는 측정값을 빠른 순서로 놓았을 때 95% 지점의 값이다. 위 수치는 실측 결과가 아닌 검증 목표다. 1GB는 1,000,000,000바이트로 계산한다.

모든 기준을 충족하면 **가능**, 절대 원칙과 자원 상한을 지키면서 일부 사용 조건을 제한해야 하면 **조건부 가능**, 정한 검증 범위에서 필수 조건을 충족하지 못하면 **불가능**으로 판정한다. 평가를 하지 않은 상태는 **미판정**이다. 세부 판정은 상세 PRD 9.5절을 따른다.

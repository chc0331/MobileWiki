# SLM Wiki POC 한 페이지 요약

문서 버전: 0.3 · 개정일: 2026-11-06 · 현재 상태: 임베딩 하위 POC 잠정 평가 완료·사람 검수 대기, 앱 실현 가능성 미판정

SLM Wiki는 한국어 기록을 기기 안에서 정리하고 변화한 상태를 추적하는 Personal Wiki 에이전트를 목표로 한다. 육아와 직장을 병행하는 사람이 병원·어린이집·여행·연차 기록을 다시 찾도록 돕는다. “지난번 소아과에서 받은 해열제 이름이 뭐였지?”라고 물으면 기록에 있는 이름과 근거 메모를 보여 준다. 기록에 없는 복용법이나 진단은 만들지 않는다.

## 무엇을 검증하나

작은 언어 모델(SLM, Small Language Model)이 스마트폰의 제한된 저장 공간과 메모리 안에서 쓸 만한 품질을 내는지 확인한다. 출시 준비보다 품질·자원·실사용의 가능성 판정이 목적이다. 먼저 PC에서 EmbeddingGemma 2의 한국어 텍스트 검색·문서 묶기 미세 조정을 시험한다. 가상 메모는 로컬 Qwen3 모델로 만든다. 생성 모델 추가 학습은 제외하고 Android 통합은 별도로 검증한다. 데이터와 모델 산출물은 Hugging Face Hub의 비공개 저장소에서 버전별로 관리한다.

| 항목 | 이번 POC의 기준 |
| --- | --- |
| 환경 | Android 12 이상, ARM64, RAM 8GB 중급기, CPU 전용 |
| 규모·입력 | 원문 1,000건. 메모·음성 인식 글·공유 글·문서·사용자 허용 알림. 문서는 TXT·Markdown·텍스트 PDF. 5,000건은 확장 시험 |
| 기능 | 기록 수집, 자동 묶음, 상태 위키, 요약·날짜 추출, 혼합 검색·질문 답변, 그래프, 수정·삭제, 수동 내보내기·복원, 견본·피드백과 기기 내 개인화 |
| 화면·처리 | 앱 목표는 메모·묶음·그래프·검색 화면. 저장 후 임시 묶음과 상태 갱신, 24시간 주기 또는 요청 시 재군집, 필요할 때 질문 답변 생성 |
| P1 오프라인 | 모델을 포함한 설치본으로 첫 실행부터 동작. 앱에 인터넷 권한 없음 |
| P2 개인정보 | 자동 외부 전송·백업·기기 이전 금지. 사용자가 직접 실행하는 내보내기만 예외 |
| P3 신뢰성 | 요약·답변 각각 사실 오류가 있는 출력 비율 5% 이하. 근거 표시와 답변 보류를 함께 평가 |
| 자원 | 임베딩·생성 모델 필수 파일 합계 1GB 이하. 모델 미로딩 상태 대비 최대 추가 메모리 1.5GB 이하 |
| 산출물 관리 | 평가용 합성 데이터와 모델·변환물은 Hugging Face Hub 비공개 저장소에서 버전 관리. 사용자 메모는 업로드하지 않음 |
| 먼저 할 임베딩 실험 | M2 Mac에서 텍스트 전용 EmbeddingGemma 2를 학습 전후 비교. 검색·묶음 품질을 확인하고 문서에 나온 표현으로 묶음 이름을 붙임 |
| 품질·속도 | 검색 상위 5개 근거 포함률 90% 이상, 답변 가능 질문 정답률 85% 이상. 검색 p95 2초·짧은 답변 p95 20초 이하 |
| 실사용 | 본인 1인·7일, S1~S10 중 8개 이상과 S11 성공, 데이터 손실 0건 |

상세 요구사항은 기능 F1~F15와 대표 시나리오 S1~S11로 검증한다. 앱 설계는 세 계층을 사용한다. L1은 등록 시각과 실제 작성·발생 시각을 구분해 원문과 버전별 검색·군집 벡터를 보관한다. L2는 한 사건·주문에 속한 기록을 묶는다. L3는 한 기록의 여러 주제 소속을 허용하고 현재 상태와 변경 이력을 함께 보여 준다. 변경이 분명하면 새 값을 먼저 반영하고 이전 근거와 되돌리기를 제공한다. 모호하면 확인을 요청한다.

개인화는 별칭과 사용자 정정 제약을 즉시 반영하는 1단계, 거리 기준과 검색 가중치를 보정하는 2단계, 충전·유휴 시 원본 벡터로 경량 어댑터를 학습하는 3단계로 나뉜다. 기반 모델을 직접 수정하거나 데이터를 자동 전송하지 않는다. 학습 후보가 기본 검증 셋 또는 사용자 확정 정답 쌍에서 F1을 낮추거나 오결합을 늘리면 이전 가중치로 자동 복원한다. 검증할 수 없으면 후보를 활성화하지 않는다. 별칭·제약·가중치는 사용자가 직접 실행한 내보내기에 포함한다.

전체 사건 쌍 F1 목표는 0.80 이상이다. 위키 상태 갱신 정확도는 90% 이상, 선 반영 오류율은 5% 이하다. 정정 제약 보존율과 악화 후보의 안전 게이트 롤백 작동률은 각각 100%가 목표다. 1,000 Triplet의 어댑터 학습 목표는 CPU 5초 이하, 가중치 1MB 이하, 추가 PSS 50MB 이하다. 단위와 평가 분모는 [상세 PRD 9절](SLM_Wiki_PRD.md#9-평가-방법과-판정)에서 정의한다.

v3 잠정 시험에서 검색 질문 250개를 모두 평가했다. 표본 100쌍 F1은 0.943, 전체 사건 쌍 499,500개의 F1은 0.832다. 검색 Recall@5는 0.840으로 목표에 미달했다. 이 수치는 사람 검수 전 자동 정답을 사용한 잠정 진단이며 앱이나 실기기의 합격 결과가 아니다.

p95는 측정값을 빠른 순서로 놓았을 때 95% 지점의 값이다. 표와 개인화 문단의 기준은 실측 결과가 아닌 검증 목표다. v3 잠정 시험 수치는 별도로 표시했다. 1GB는 1,000,000,000바이트로 계산한다.

현재 Android POC는 문서·직접 입력·지원 기기의 한국어 음성 인식 글을 하나의 실험 목록으로 묶는다. 사용자가 실행하면 군집별 목록과 PCA 지도를 보여 준다. 이전 생활 화면과 알림 수집은 숨겼고 기존 데이터는 보존한다. 이는 위 표의 앱 전체 기능을 완성했다는 뜻이 아니다. 실기기 음성·속도와 품질 결과는 별도 검증 전까지 미판정이다. 자세한 사용법은 [Android POC 안내](android/README.md)에서 확인한다.

모든 기준을 충족하면 **가능**, 절대 원칙과 자원 상한을 지키면서 일부 사용 조건을 제한해야 하면 **조건부 가능**, 정한 검증 범위에서 필수 조건을 충족하지 못하면 **불가능**으로 판정한다. 평가를 하지 않은 상태는 **미판정**이다. 세부 판정은 상세 PRD 9.5절을 따른다.

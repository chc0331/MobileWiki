# EmbeddingGemma 2 지름길 제거·Hard Negative 개선 실험 결과

기록일: 2026-10-28 · 상태: **잠정 결과**. 고정 평가 자료 240개 항목의 사람 검수는 아직 끝나지 않았다. 아래 수치는 합성 자료에 대한 자동 평가 결과다.

## 실험 범위

검색 질문에 인물 이름과 메모 위치가 반복해서 나타나던 구조를 바꾸고, 같은 가족의 다른 사건을 군집 학습의 어려운 음성 예시로 추가했다. 답은 네 메모 중 d0~d3 어디에나 균형 있게 배치했다. 사건의 절반가량은 이름을 질문과 본문에서 생략했다. 메모와 질문에는 ISO 날짜와 한국어 날짜를 섞었다.

군집 음성 예시는 같은 가족의 다른 사건(A) 400개, 같은 주제의 다른 가족 사건(B) 240개, 다른 주제·가족이지만 날짜가 30일 이내이거나 사실값이 같은 사건(C) 160개로 구성했다. 전체 사건은 가족과 사건 단위로 학습·개발·시험 분할에 나눴다.

## 자료와 실행 기록

로컬 Qwen3 8B로 가상 사건 525개를 만들었다. 사건마다 메모 네 개가 있어 총 2,100개다. 학습에는 메모 800개, 검색 질문 200개, 세 쌍 학습 예시 1,000개를 사용했다. 세 쌍 예시 중 200개는 검색용이고 800개는 군집용이다. 개발 자료에는 메모 300개와 문서 쌍 100개가 있다. 고정 시험 자료에는 메모 1,000개, 검색 질문 250개, 문서 쌍 100개가 있다. 검색 평가는 시험 질문 중 고정 순서의 140개를 사용했다.

모델이 반복하거나 다른 사건과 겹치는 문장을 낸 사건은 다시 생성했다. 최종 원본 525개 사건 중 39개 사건을 중복 복구 과정에서 교체했으며, 재생성 이력에는 이전 사건 자료 43개가 보존돼 있다. 날짜·답 위치·인물 표현 보정과 단서 제거 후 전체 중복, 분할, 답 근거, 파일 해시 검사를 통과했다. 단서 제거 과정에서 516건의 수정 기록이 남았다. 연락처·주민번호·이메일 형태는 발견되지 않았다.

교사 모델은 `qwen3:8b`이며 digest는 `500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`이다. 기반 임베딩 모델은 `google/embeddinggemma-2`, revision은 `f9972ac22e696a105c482202646979e33e4b5a1e`다. 데이터 생성·복구에는 약 7시간 40분이 걸렸다.

M2 Mac의 MPS에서 LoRA를 2회 학습했다. 학습 가능한 가중치는 524,288개이고 총 250단계를 실행했다. 학습 시간은 약 8분 44초, 최종 손실은 0.0188이다. 개발 자료에서 `checkpoint-250`과 군집 거리 기준값 0.15를 선택했다. 학습과 개발 자료는 시험 자료와 분리했다.

## 고정 시험 결과

기준 모델과 학습 모델은 같은 데이터 revision과 같은 평가 절차를 사용했다. 전체 사건 쌍 F1은 메모 1,000개의 모든 쌍을 생성 사건 ID와 비교해 계산한다. 표본 문서 쌍 F1에서 놓칠 수 있는 과합침도 이 지표로 확인할 수 있다.

| 지표 | 기준 모델 | 개선 모델 | 이전 revision 모델 |
| --- | ---: | ---: | ---: |
| 검색 Recall@1 | 46/140 (32.9%) | 52/140 (37.1%) | 113/140 (80.7%) |
| 검색 Recall@5 | 98/140 (70.0%) | 93/140 (66.4%) | 134/140 (95.7%) |
| 검색 MRR | 0.501 | 0.513 | 0.877 |
| 표본 문서 쌍 100개 F1 | 0.152 | 0.876 | 0.990 |
| 전체 사건 쌍 F1 | 0.038 | 0.348 | 0.529 |
| 전체 사건 쌍 과합침 수 | 2,893 | 4,203 | 2,624 |

개선 모델의 표본 문서 쌍은 관련 50쌍 중 39쌍을 찾고 11쌍을 놓쳤다. 무관한 50쌍은 합치지 않았다. 이에 따라 표본 F1은 PRD 목표인 0.80을 넘었다. 그러나 전체 사건 쌍 기준 정밀도는 0.223, 재현율은 0.802다. 모델이 합친 쌍 가운데 다른 사건을 잘못 합친 경우가 많아 전체 F1은 0.348에 그쳤고, 과합침은 4,203쌍이었다.

검색 Recall@5는 기준 모델보다 5개 항목 줄었고, 목표 90%에도 못 미쳤다. MRR은 0.501에서 0.513으로 조금 올랐고 Recall@1은 32.9%에서 37.1%로 올랐다. 따라서 이 학습은 검색 품질 목표를 달성하지 못했다.

지름길 기준선에서 이름만 사용한 규칙의 Recall@5는 이름이 드러난 질문 71개 중 13개(18.3%)였다. 그 질문에서 인물과 d0 위치를 함께 우선한 규칙은 21개(29.6%)를 찾았다. 전체 140개 질문에 d0만 우선한 규칙은 2개(1.4%)를 찾았다. 개선 모델은 이 기준선보다 높은 Recall@5를 보였지만, 이전 revision의 95.7%보다 낮다.

이전 revision과 새 revision은 서로 다른 합성 사건 자료에서 측정했다. 두 결과는 개선 방향을 살피는 참고값이다. 같은 사건에서 직접 비교한 통제 실험 결과는 아니다.

## 판정과 남은 확인

답 위치 회전, 인물 이름 노출 축소, 날짜 표기 다양화와 A/B/C 어려운 음성 예시를 구현했다. 새 시험 자료에서 이름·위치 기준선은 낮아졌고, 개선 모델은 기준 모델보다 문서 쌍 F1과 전체 사건 쌍 F1이 높았다. 다만 전체 군집화 과합침은 여전히 크다. 검색 Recall@5도 목표에 미달한다. 따라서 이 revision은 제안된 지름길을 줄였지만 검색·군집 품질 목표를 모두 해결하지 못했다.

시험 질문 140개와 문서 쌍 100개, 총 240개 항목은 사람 검수 전이다. 표본 문서 쌍 F1 0.876을 최종 합격으로 판단하지 않는다. 검수 표본 240개와 태그 검토용 묶음 30개를 사람이 확인해야 한다. 실제 사용자 메모, 새 주제, Android 기기 성능은 이 실험에서 측정하지 않았다.

## 로컬 산출물

산출물은 Git에 포함되지 않는 `poc/embedding/artifacts/shortcut-hardneg-v2-balanced/`에 있다.

- `dataset/manifest.json`: 데이터 revision, 파일 해시, 분할 수와 음성 예시 구성을 기록한다.
- `dataset/review.csv`: 검색 질문 140개와 문서 쌍 100개의 사람 검수표다.
- `trained/training.json`: 기반 모델 revision, 학습 설정, 실행 환경과 손실을 기록한다.
- `evaluation/base.json`, `evaluation/tuned.json`: 기준 모델과 개선 모델의 상세 평가 결과다.
- `evaluation/tuned.tag_review.csv`: 묶음 태그와 예시 문서 30개의 검토표다.
- `raw_events.jsonl`, `curated_events.jsonl`: 생성 원본, 정제 자료와 재생성 이력을 담는다.

이 자료는 잠정 평가용 로컬 산출물이다. 사람 검수 전 결과를 공식 품질 판정이나 배포 자료로 사용하지 않는다.

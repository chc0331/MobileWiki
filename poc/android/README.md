# Android 문서 군집 실험 POC

Android 12 이상 ARM64 기기에서 문서 임베딩과 군집 결과를 확인하는 로컬 POC입니다. 화면에는 문서 수집과 군집 확인 메뉴만 표시합니다. 앱에는 인터넷 권한이 없으며 추출한 글·임베딩·정답 주제는 앱 전용 저장소에 보관합니다. Android 자동 백업과 기기 이전 대상에서도 제외합니다.

## 문서 군집 실험 안내

`문서` 탭에서 `기기 문서 스캔`을 누르면 앱이 공유 저장소를 검색합니다. 접근 권한이 있는 하위 폴더를 대상으로 삼습니다. 처음 실행할 때는 Android 설정에서 ‘모든 파일 접근’을 허용해야 합니다. 다른 앱의 비공개 파일과 클라우드에만 있는 문서는 검색하지 않습니다. 원본 파일은 옮기거나 수정하지 않습니다. 스캔 중에는 진행 상태를 확인하고 취소할 수 있습니다.

UTF-8 TXT·Markdown과 텍스트 PDF를 처리합니다. 스캔 PDF는 지원하지 않습니다. 10MB를 넘는 파일과 20,000자를 넘는 TXT·Markdown은 제외합니다. PDF는 50쪽 또는 추출한 글 100,000자를 넘으면 제외합니다. 읽지 못한 파일·폴더와 제한에 걸린 파일은 스캔 결과에 이유별로 표시합니다.

다시 스캔할 때 파일 크기와 수정 시각이 같으면 기존 임베딩을 재사용하고, 달라지면 다시 처리합니다. 정답 주제는 그대로 둡니다. 저장소 검색이 끝난 경우에만 사라진 자동 수집 문서를 앱 목록에서 정리합니다. 자동 수집 문서를 앱에서 삭제해도 기기에 있는 원본은 삭제하지 않습니다. `문서 가져오기`를 눌러 파일을 직접 선택할 수도 있습니다. 등록하기 전에 추출한 글을 확인하며 PDF 원본은 앱 내부에 복사합니다.

같은 주제의 문서에는 같은 정답 주제 이름을 입력합니다. 라벨을 비워 둔 문서는 군집에는 포함하지만 정량 지표 계산에서는 제외합니다.

`군집` 탭에서 임베딩 결과를 2D PCA 지도로 확인할 수 있습니다. 두 손가락으로 지도를 확대하거나 이동하고 점을 누르면 문서 글과 정답 주제를 볼 수 있습니다. 아래 목록에는 군집별 문서와 👍·👎 의견이 표시됩니다. 거리 임계값은 0.00~2.00 범위에서 0.01씩 조절하며 기본값은 0.05입니다. 기준을 바꾸면 군집과 지표를 다시 계산합니다.

정밀도·재현율·F1은 정답 라벨이 입력된 문서 쌍만으로 계산합니다. 라벨 비율과 평가에 사용한 문서 수도 함께 표시합니다. PCA 지도는 768차원 임베딩을 2차원으로 펼쳐 보여 줍니다. 점 사이의 거리를 군집 품질 점수로 해석하지 않습니다. 고정 평가 데이터와 기준값은 군집 실험과 분리해 유지합니다.

## 확인 순서

1. `문서` 화면에서 `기기 문서 스캔`을 누르고 필요한 접근 권한을 허용합니다.
2. 스캔 결과에서 처리한 문서와 제외한 문서의 수를 확인합니다.
3. `군집` 화면에서 점 지도와 군집 목록을 살펴보고 거리 임계값을 바꿔 봅니다.
4. 품질 지표가 필요하면 `문서` 화면에서 문서별 정답 주제를 입력합니다.

## 빌드

모델 변환 도구는 `poc/embedding/.venv`의 Python 환경과 로컬 학습 어댑터를 사용합니다. 고정 평가 자료와 모델을 만든 뒤 Android 폴더에서 APK를 빌드합니다.

```bash
python3 poc/android/tools/package_eval_data.py
PYTHONPATH=poc/embedding poc/embedding/.venv/bin/python poc/android/tools/export_embedding_model.py --precision int8_embedding
cd poc/android
./gradlew assembleDebug
```

APK 위치:

```text
poc/android/app/build/outputs/apk/debug/app-debug.apk
```

APK에는 ONNX 모델과 토크나이저가 포함됩니다. 모델 파일은 크기 때문에 Git에서 제외합니다. 앱은 ONNX Runtime CPU를 사용해 비행기 모드에서 실행하며, 모델 파일과 토크나이저의 SHA-256, 기준 모델 revision, 선택된 어댑터 checkpoint를 확인합니다. 검증된 학습 모델을 불러오지 못하면 기본 모델로 대체하지 않습니다.

LiteRT 변환본은 기준 임베딩과 일치하지 않아 사용하지 않습니다. Android용 ONNX Runtime CPU 모델은 행별 int8 토큰 임베딩과 float32 Transformer로 내보냈고, Python ONNX Runtime에서 패딩·동적 길이 입력 모두 기준 임베딩과 코사인 유사도 0.999 이상인지 확인했습니다. ONNX 모델과 토크나이저를 비공개 Hub 저장소 revision `dbb3bdd252f9034681cb65efee5d7f4b8cbef7bf`에 올렸고, artifact revision과 파일 해시를 기록한 최신 저장소 revision은 `526a59e58e244680fd076a58e646cdd3f4efd1bc`입니다. 앱 manifest에는 소스 모델·artifact revision과 파일 해시를 기록합니다.

## 확인하지 않은 항목

연결된 실기기나 에뮬레이터가 없는 환경에서는 설치 후 오프라인 동작, 실제 CPU 지연, 추가 PSS, Android 백업·이전 동작을 검증할 수 없습니다. POC가 생성하는 결과는 사용자 검토와 대상 기기 측정 전까지 잠정 또는 미판정입니다.

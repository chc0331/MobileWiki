# Android 입력·군집 실험 POC

Android 12 이상 ARM64 기기에서 문서, 직접 입력한 글, 음성으로 인식한 글을 함께 묶어 보는 실험 앱입니다. 현재 화면은 입력 목록과 군집 결과로 구성합니다. 앱에는 인터넷 권한이 없고 글과 임베딩은 앱 전용 저장소에 보관합니다. Android 자동 백업과 기기 이전 대상에서도 제외합니다.

## 입력과 군집 실행

1. `문서`에서 파일을 선택하거나 `기기 문서 스캔`을 누릅니다. 파일 선택은 여러 개를 고를 수 있습니다. 스캔은 Android의 모든 파일 접근 권한을 받은 뒤 접근 가능한 공유 저장소와 하위 폴더를 검색합니다. 다른 앱의 비공개 파일과 클라우드 전용 파일은 검색하지 않습니다. 파일 선택기는 다른 앱의 클라우드 파일을 제공할 수도 있으므로 오프라인 시험에는 기기에 저장된 파일을 고릅니다. 스캔 진행 상태와 취소, 제외 사유를 확인할 수 있습니다.
2. UTF-8 TXT·Markdown과 텍스트 PDF를 처리합니다. 파일은 10MiB(10,485,760바이트)까지 읽습니다. TXT·Markdown은 20,000자까지, PDF는 50쪽과 추출한 글 100,000자까지 허용합니다. 암호 PDF, 스캔 PDF와 제한을 넘는 문서는 이유를 표시하고 제외합니다. 스캔에서는 기기 원본을 복사하거나 수정하지 않습니다. 직접 선택한 PDF는 앱 내부에 사본과 추출한 글을 보관합니다.
3. `직접 입력`에서는 글을 작성합니다. `음성`은 Android의 기기 내 한국어 음성 인식을 사용합니다. 마이크 권한을 허용한 뒤 말하고 인식된 글을 확인·수정해 저장합니다. 앱은 녹음 파일을 보관하지 않으며 온라인 인식으로 전환하지 않습니다. 기기에 인식 서비스나 한국어가 준비되지 않으면 음성을 사용할 수 없다고 안내합니다. 이때는 직접 입력할 수 있습니다.
4. 직접 입력과 음성 인식 결과는 20,000자까지 저장합니다. 제목을 비우면 내용의 첫 줄을 제목으로 사용하며 제목은 수정할 수 있습니다. 실험 목록에는 제목만 표시합니다. 항목을 누르면 제목과 전체 내용, 정답 주제를 확인할 수 있습니다.
5. 글을 모은 뒤 `군집 실행`을 누릅니다. 입력과 스캔만으로는 임베딩이나 군집을 실행하지 않습니다. 실행 시 현재 모델과 처리 방식으로 만든 임베딩을 재사용하고 나머지를 새로 계산합니다. 진행 상태를 보며 취소할 수 있습니다. 실패하거나 메모리가 부족하면 일부 결과를 전체 결과로 표시하지 않습니다.

스캔한 파일의 크기와 수정 시각이 같으면 기존에 추출한 글을 유지합니다. 값이 바뀌면 다시 읽습니다. 과거 앱에서 스캔한 파일도 다시 발견하면 새 실험에 추가합니다. 과거 임베딩에는 모델 정보가 없어 새 실험에서 처음 사용할 때 다시 계산합니다. 전체 스캔이 정상적으로 끝난 경우에만 사라진 스캔 항목을 새 실험 목록에서 정리합니다. 기기 원본은 삭제하지 않습니다.

## 결과와 평가

결과 화면에서 군집 수, 군집별 기록 수와 제목, 미분류 기록 수를 확인합니다. 군집을 열면 모든 기록을 볼 수 있습니다. 2D PCA 지도는 임베딩을 두 차원으로 줄여 표시합니다. 두 손가락으로 확대·이동하고 점을 누르면 기록을 열 수 있습니다. 지도에서 보이는 거리는 원래 임베딩 거리와 정확히 같지 않을 수 있습니다.

`평가와 거리 기준`을 열면 거리 기준을 0.00~2.00 범위에서 0.01씩 바꿀 수 있습니다. 기본값은 0.05입니다. 기준을 바꾼 뒤에는 `군집 다시 실행`을 눌러야 결과가 갱신됩니다. 각 기록의 `정답 주제`에 같은 이름을 입력하면 해당 기록 쌍의 정밀도·재현율·F1을 계산합니다. 라벨이 없는 기록은 군집에 포함하지만 품질 지표에서는 제외합니다.

새로 계산한 임베딩의 경과 시간을 합산해 표시합니다. 군집 계산 시간은 따로 보여 줍니다. 임베딩 재사용 건수도 함께 보여 줍니다. 모델 준비와 PCA 지도 계산은 각각의 시간에 포함하지 않습니다. 시간은 기기와 실행 환경에 따라 달라지므로 에뮬레이터 수치를 실기기의 성능으로 해석하지 않습니다.

마지막 성공 결과는 앱을 다시 열어도 남습니다. 입력이나 거리 기준이 바뀌면 이전 결과에 재실행이 필요하다고 표시하고 품질 지표는 새 실행 뒤 다시 보여 줍니다. 삭제한 기록은 이전 결과와 지도에서도 빠집니다. 실험 목록을 비우면 이번 실험의 글과 임베딩, 결과를 삭제합니다.

## 이전 앱 데이터

업데이트 전 문서와 생활 기록은 새 실험에 자동으로 포함하지 않습니다. 기존 기록과 기기 원본은 보존합니다. 이전에 스캔한 파일을 다시 스캔하면 이번 실험에 등록하며 같은 경로에 있던 정답 주제가 있으면 가져옵니다. 실험에서 기록을 삭제하거나 목록을 비워도 업데이트 전 데이터는 삭제하지 않습니다.

생활 화면과 알림 수집은 현재 화면에서 숨겼으며 새 알림은 수집하지 않습니다. 기존 알림은 이전의 30일 보관 조건을 유지합니다. Android의 백그라운드 작업이 지연되면 실제 정리 시점도 늦어질 수 있습니다. 이전에 승인한 일정과 할 일은 지우지 않습니다. 앱 데이터 삭제는 논리적 삭제이며 저장 장치의 물리적 완전 삭제를 보장하지 않습니다.

## 빌드

모델 변환 도구는 `poc/embedding/.venv`의 Python 환경과 로컬 학습 어댑터를 사용합니다. 고정 평가 자료와 모델을 만든 뒤 Android 폴더에서 APK를 빌드합니다.

```bash
python3 poc/android/tools/package_eval_data.py
PYTHONPATH=poc/embedding poc/embedding/.venv/bin/python poc/android/tools/export_embedding_model.py --precision int8_embedding
cd poc/android
./gradlew assembleDebug
```

APK 위치:

```text
poc/android/app/build/outputs/apk/debug/app-debug.apk
```

APK에는 ONNX 모델과 토크나이저가 포함됩니다. 모델 파일은 크기 때문에 Git에서 제외합니다. 앱은 ONNX Runtime CPU를 사용해 비행기 모드에서 실행하며, 모델 파일과 토크나이저의 SHA-256, 기준 모델 revision, 선택된 어댑터 checkpoint를 확인합니다. 검증된 학습 모델을 불러오지 못하면 기본 모델로 대체하지 않습니다.

LiteRT 변환본은 기준 임베딩과 일치하지 않아 사용하지 않습니다. Android용 ONNX Runtime CPU 모델은 행별 int8 토큰 임베딩과 float32 Transformer로 내보냈고, Python ONNX Runtime에서 패딩·동적 길이 입력 모두 기준 임베딩과 코사인 유사도 0.999 이상인지 확인했습니다. ONNX 모델과 토크나이저를 비공개 Hub 저장소 revision `dbb3bdd252f9034681cb65efee5d7f4b8cbef7bf`에 올렸고, artifact revision과 파일 해시를 기록한 최신 저장소 revision은 `526a59e58e244680fd076a58e646cdd3f4efd1bc`입니다. 앱 manifest에는 소스 모델·artifact revision과 파일 해시를 기록합니다.

## 확인하지 않은 항목

한국어 음성 인식은 기기의 시스템 인식 서비스와 언어 지원 상태에 따라 사용하지 못할 수 있습니다. 지원하는 실기기의 비행기 모드에서 음성 인식 품질과 동작을 별도로 확인해야 합니다. 앱의 인터넷 권한이 없다는 사실만으로 다른 시스템 서비스의 모든 통신까지 검증한 것은 아닙니다.

대상 실기기의 처리 시간·메모리와 Android 백업·이전 동작은 별도 측정이 필요합니다. 실제 자료의 품질은 정답 주제를 입력하고 평가하기 전까지 미판정입니다.
